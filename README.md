# 老子 · 思维操作系统（laozi-perspective）

> 道可道，非常道；名可名，非常名。——《道德经》第一章

基于《道德经》通行本（王弼本）、马王堆帛书本、郭店楚简本及历代注疏蒸馏的**老子思维框架 Skill**。

## 这是什么

一个可独立调用的人物 Skill，帮你用老子的镜片审视问题——尤其是那些"用力过猛、争得太狠、不知何时该停"的问题。

内含：
- **6 个核心心智模型**：道不可名、反者道之动、无为而无不为、柔弱胜刚强（上善若水）、知足知止、返朴归真
- **8 条决策启发式**：物极必反、图难于其易、慎终如始、将欲取之必固与之……
- **完整表达 DNA**：格言体、对偶排比、正言若反、自然意象
- 价值观与内在张力、智识谱系、诚实边界
- **6 份可溯源的调研底稿**（`references/research/`）

## 用法（触发词）

把 `SKILL.md` 放进你的 Agent 技能目录后，提到以下词即可激活：

「用老子的视角」「老子会怎么看」「道德经思维」「无为」「上善若水」「反者道之动」「物极必反」「道法自然」「知足常乐」「以柔克刚」

## 目录结构

laozi-perspective/
