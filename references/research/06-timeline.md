# 06 · 人物时间线（老子）

## 说明
老子生卒年无定论，且其人与《道德经》成书是否同一时段有争议。以下为"主流说法 + 争议"并列，不作定论。

## 时间线

| 时间（约） | 事件 | 备注/争议 |
|------|------|----------|
| 约前 570 年（胡适说） | 老子生，晚于/早于孔子有争议 | 胡适：老子比孔子至多大 20 岁 |
| 春秋末期 | 任周守藏室之史，孔子问礼 | 傅斯年否定孔子问礼；冯友兰认为无关紧要 |
| 春秋末/战国初 | 见周衰，西出函谷关 | 《史记》载 |
| 出关时 | 应尹喜请，著《老子》五千言，后隐 | 成书年代学界分歧极大 |
| 约前 300 年 | 郭店楚简《老子》抄写（战国中期） | 最早实物，约今本 1/3 |
| 约前 200 年 | 马王堆帛书《老子》抄写（西汉初） | 德经在前 |
| 约前 168 年 | 帛书下葬（汉文帝前元十二年） | 年代锚点 |
| 约 240 年 | 王弼注本（通行本） | 81 章定型 |
| 东汉以降 | 老子被道教神化为"太上老君" | 已非历史老子 |

## 身份四说（《史记》并列，司马迁"世莫知其然否"）
1. 李耳，字聃（主流采纳）
2. 老莱子（楚国隐者，与孔子同时）
3. 太史儋（后孔子百余年，西入秦）
4. 或谓老子为长寿之隐者

## 现代学界共识（谨慎表述）
- 《老子》一书并非一人一时写成，经数代道家学者编纂增删，战国中晚期至西汉初定型。
- "老子"作为思想人格是确定的（文本在）；作为历史个人的具体身份，无法确证。

## 最新动态（截至 2026-09）
- 郭店楚简（1993）、帛书（1973）出土后，学界持续以简帛本校正通行本误读（如"大器免成"vs"大器晚成"、"绝伪弃虑"vs"绝仁弃义"）。
- 老子其人其书研究仍在推进，但无颠覆性新史料出现。
